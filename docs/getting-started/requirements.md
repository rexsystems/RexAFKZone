| | |
|---|---|
| Java | 21 |
| Server | Paper, Purpur, or Folia 1.21 or newer |
| Optional | PlaceholderAPI |

The reward check runs on each player's own scheduler, so the same jar runs on Folia. Reward commands are dispatched from the console on the global region scheduler.

WorldEdit, FastAsyncWorldEdit, and similar region plugins are not required. The wand stores two block positions for `/rexafkzone create`.
